# Estimates

We almost never know a population's true parameters — the real expected return, the real default rate, the real mean. We only have a **sample**. **An estimate is a specified, observed numerical value used to estimate an unknown population parameter.** This lesson names the two kinds.

## 1. Point estimate

**A point estimate is a single numerical value used to estimate an unknown population parameter.** The classic example: **the sample mean $\bar{x}$ is a point estimate of the population mean $\mu$.**

Imagine the true population mean is $\mu = 65$ but hidden from you. You draw a sample and its mean comes out $\bar{x} = 60$. That one number, 60, is your point estimate — your single best guess for the unknown 65:

$$
\mu \;\longleftarrow\; \bar{x} \qquad (\text{the sample mean stands in for the population mean})
$$

Other point estimates follow the same pattern: the **sample proportion** estimates the true probability, the **sample variance** estimates $\sigma^2$ (this is exactly why it divides by [$n-1$](/docs/Statistics/descriptive-statistics/summary-measures/why-n-minus-1) — to be an unbiased estimator).

The weakness of a point estimate is that it's **silent about its own uncertainty.** Reporting "60" hides the fact that another sample might have given 58, or 63. It looks more confident than it has any right to be.

## 2. Interval estimate

**An interval estimate is a *range* of values used to estimate the unknown population parameter.** Instead of a lone "60," you report a band — say **55 to 65** — that plausibly contains the true mean. That range is a **confidence interval**, and it's built by placing the point estimate in the middle and reaching out on either side:

An interval estimate is **honest**: its *width* communicates the uncertainty a point estimate hides. A narrow interval says "I'm fairly sure"; a wide one says "I really don't know."

## Where the width comes from: the CLT

This is where the previous lesson pays off. The [Central Limit Theorem](/docs/Probability/distributions/sampling-and-estimation/central-limit-theorem) tells us the sample mean is approximately $\bar{X} \sim N(\mu, \sigma/\sqrt{n})$ — so the **standard error $\sigma/\sqrt{n}$ sets the reach** of the interval. A common 95% confidence interval is

$$
\bar{x} \;\pm\; 1.96 \cdot \frac{\sigma}{\sqrt{n}}
$$

Bigger $n$ ⇒ smaller standard error ⇒ **narrower** interval ⇒ a sharper estimate. The full mechanics — confidence levels, $t$ vs $z$, margins of error — live in [Inferential Statistics](/docs/Statistics/inferential-statistics).

```python
import numpy as np
rng = np.random.default_rng(1)

# unknown population: mean 65. We only get a sample.
population = rng.normal(65, 12, size=1_000_000)
sample = rng.choice(population, size=40, replace=False)

xbar = sample.mean()                       # point estimate
se   = sample.std(ddof=1) / np.sqrt(len(sample))
lo, hi = xbar - 1.96*se, xbar + 1.96*se    # 95% interval estimate

print(f"point estimate  x̄ = {xbar:.1f}")
print(f"interval estimate = [{lo:.1f}, {hi:.1f}]  (95% confidence)")
print(f"(true μ = 65 — the interval is built to contain it ~95% of the time)")
```

## Why a quant cares

**In markets, every number you report is an estimate — and pretending otherwise is how people blow up.**

- **An expected return is a point estimate** with a huge standard error. Estimating a mean return to a useful precision takes *decades* of data (the $\sqrt{n}$ law again), which is why backtests over-promise: the point estimate looks great, the interval around it is enormous.
- **A Sharpe ratio, a volatility, a correlation, a beta** — all point estimates from finite samples, all with confidence intervals that risk reports usually omit. Two strategies with the same estimated Sharpe can have wildly different *reliability*.
- **Interval thinking is risk thinking.** "Expected P&L is \$2m" is a point estimate; "\$2m, 95% interval [−\$4m, +\$8m]" tells you whether you can survive the downside. The interval, not the point, is the decision-relevant object.

Report the point, but *size your risk to the interval*. That single habit separates a robust process from a fragile one.
