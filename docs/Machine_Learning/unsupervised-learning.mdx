# Unsupervised Learning

Supervised learning needs an answer key. **Unsupervised** learning has none — just the features $X$ — and its job is to **discover structure the data was hiding**: which rows group together, which dimensions actually carry the information, and which points don't belong at all. In finance that means **market regimes, factor structure, and outlier/fraud detection.**

## Dimensionality reduction: PCA

Real datasets often have dozens of correlated features that secretly live in a much smaller space. **Principal Component Analysis (PCA)** finds a new set of axes — the **principal components** — ordered by how much variance they explain. The first component is the single direction of greatest spread; each next one is orthogonal to the last and captures the most remaining variance.

Keep the top few components and you **compress the data with minimal information loss** — which denoises it, speeds up downstream models, and makes it visualizable. Mechanically, the components are the **eigenvectors of the covariance matrix**, and their eigenvalues are the variance explained.

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.datasets import make_classification

X, _ = make_classification(n_samples=300, n_features=10, n_informative=4, random_state=0)
pca = PCA().fit(X)
ev = pca.explained_variance_ratio_
print("variance explained per component:", np.round(ev, 3))
print("cumulative                     :", np.round(np.cumsum(ev), 3))
print("components needed for 90% of the variance:",
      int(np.searchsorted(np.cumsum(ev), 0.90) + 1))
```

In quant work PCA is everywhere: the first few components of a basket of yields *are* the classic **level / slope / curvature** of the term structure; PCA on a universe of stock returns recovers **market and sector factors**. Always **scale features first** — PCA chases variance, so an unscaled large-unit feature would hijack the components.

**In quant terms** — run PCA on daily yields across maturities and the first **three** components explain almost everything, corresponding to level, slope, and curvature:

```python
import numpy as np
from sklearn.decomposition import PCA

rng = np.random.default_rng(3)
mats = np.array([0.25, 0.5, 1, 2, 3, 5, 7, 10, 20, 30])   # maturities in years
n = 400
level = rng.normal(0, 1, n); slope = rng.normal(0, 1, n); curv = rng.normal(0, 1, n)
curves = (level[:, None]                                    # parallel shift
          + slope[:, None] * (mats / 30)                    # steepening/flattening
          + curv[:, None] * np.exp(-((mats - 3) ** 2) / 8)  # a hump in the belly
          + rng.normal(0, 0.05, (n, len(mats))))

pca = PCA(n_components=3).fit(curves)
print("variance explained by PC1, PC2, PC3:", np.round(pca.explained_variance_ratio_, 3))
print("cumulative:", round(pca.explained_variance_ratio_.sum(), 3),
      "-> PC1=level, PC2=slope, PC3=curvature")
```

Three numbers summarize an entire yield curve — that's the compression PCA buys you, and it's the backbone of fixed-income risk models.

## Clustering: grouping without labels

### K-Means

The workhorse. You pick **k**, and the algorithm alternates: assign each point to its nearest **centroid**, then move each centroid to the mean of its points — repeating until stable. It minimizes **inertia** (within-cluster squared distance).

Its limitations are worth knowing: you must choose *k* up front, it assumes **round, similar-sized** clusters, and it's sensitive to initialization (use `k-means++`, the default). To choose *k*, use the **elbow** (where inertia stops dropping fast) or the **silhouette score** (below).

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

rng = np.random.default_rng(0)
X = np.vstack([rng.normal(c, 0.6, (80, 2)) for c in [(-3, -3), (0, 3), (3, -2)]])  # 3 true blobs

for k in [2, 3, 4, 5]:
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X)
    print(f"k={k}  inertia={km.inertia_:7.1f}  silhouette={silhouette_score(X, km.labels_):.3f}")
```

The silhouette peaks at **k = 3** — the algorithm recovers the true number of groups.

### Hierarchical clustering

Instead of committing to *k*, **agglomerative** clustering starts with every point as its own cluster and repeatedly **merges the two closest** clusters, building a tree — the **dendrogram**. You cut the tree at whatever height gives the number of clusters you want. It's great for **exploration** (you *see* the nested structure) and doesn't assume round clusters, but it's slower on large data. The **linkage** rule (single / complete / average / Ward) controls what "closest" means.

**In quant terms** — cluster stocks by their **return-correlation profile** to find groups that move together (for diversification, or a statistical alternative to sectors):

```python
import numpy as np
from sklearn.cluster import AgglomerativeClustering

rng = np.random.default_rng(4)
T = 250                                          # trading days
sector_factor = rng.normal(0, 1, (T, 3))         # 3 hidden "sector" drivers
returns, truth = [], []
for s in range(3):
    for _ in range(5):                            # 5 stocks per sector
        returns.append(0.8 * sector_factor[:, s] + rng.normal(0, 0.6, T))
        truth.append(s)

corr = np.corrcoef(np.array(returns))            # 15x15 correlation matrix
labels = AgglomerativeClustering(n_clusters=3).fit_predict(corr)   # group by correlation profile
print("clusters found:", labels.tolist())
print("true sectors  :", truth)
```

The algorithm recovers the three hidden groups purely from how the stocks co-move — no sector labels needed. That's the idea behind correlation-based portfolio construction.

### DBSCAN — density-based

**DBSCAN** takes a completely different view: clusters are **dense regions** separated by sparse ones. It needs no *k*, finds **arbitrary shapes**, and — crucially — labels sparse points as **noise** instead of forcing them into a cluster. Its two knobs are `eps` (neighborhood radius) and `min_samples` (how many points make a dense core).

```python
import numpy as np
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

X, _ = make_moons(n_samples=300, noise=0.06, random_state=0)   # two interleaving crescents
labels = DBSCAN(eps=0.2, min_samples=5).fit_predict(X)
n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
print("clusters found:", n_clusters)
print("points labelled as noise (-1):", int(np.sum(labels == -1)))
```

K-Means would butcher those crescents (it wants round blobs); DBSCAN nails the two curved clusters and flags stray points as noise.

## Did the clustering actually work? The silhouette score

With no labels, how do you judge a clustering? The **silhouette score** measures, for each point, how much closer it is to its *own* cluster than to the *nearest other* cluster, scaled to $[-1, 1]$:

- **near +1** → tight, well-separated clusters.
- **near 0** → overlapping clusters / on a boundary.
- **negative** → the point is probably in the wrong cluster.

Averaged over all points, it's the standard way to compare clusterings and pick *k*.

## Anomaly detection

Sometimes the interesting rows are the ones that **don't** fit — fraud, fat-finger trades, a stock behaving unlike its peers. Two unsupervised detectors:

- **Isolation Forest** — builds random trees; anomalies get **isolated in very few splits** because they're far from everything else. Fast and scales well.
- **Local Outlier Factor (LOF)** — flags points whose local density is much lower than their neighbors'. Good for anomalies that are only unusual *relative to their neighborhood*.

```python
import numpy as np
from sklearn.ensemble import IsolationForest

rng = np.random.default_rng(0)
X = np.vstack([rng.normal(0, 1, (200, 2)),      # 200 "normal" points
               rng.uniform(-6, 6, (20, 2))])     # 20 scattered outliers
pred = IsolationForest(contamination=0.1, random_state=0).fit_predict(X)   # -1 = anomaly
print("flagged as anomalies:", int(np.sum(pred == -1)), "of", len(X))
```

## Where this lands in quant work

| Tool | Quant use |
|---|---|
| **PCA** | Yield-curve level/slope/curvature; equity risk factors; denoising signals |
| **K-Means / GMM** | Market-**regime** detection (calm vs. crisis) |
| **Hierarchical** | Clustering assets by correlation for diversification |
| **DBSCAN** | Finding non-obvious groups; isolating noise |
| **Isolation Forest / LOF** | Fraud, bad ticks, unusual trading behavior |

The catch that mirrors supervised learning: **there's no answer key, so validation is judgment plus metrics** (silhouette, explained variance, stability under resampling). And on non-stationary market data, a regime map fit on last year may not describe this year — re-fit and sanity-check.
