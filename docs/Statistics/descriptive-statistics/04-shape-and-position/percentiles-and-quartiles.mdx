# Percentiles and Quartiles

Central tendency and dispersion summarize a distribution; **percentiles locate a specific value within it.** They're how you say "this observation is high" or "this is a bad day" precisely, without assuming any particular distribution shape.

## Percentage vs. percentile — not the same word

Worth separating first, because they sound alike:

- A **percentage** is a fraction out of 100. In the set $\left[1,2,3,4,5,6\right]$ there are 3 odd numbers, so the percentage of odds is $\frac{3}{6}\times 100 = 50\%$. It's about *composition*.
- A **percentile** is about *relative standing* — a value below which a given percentage of the data falls.

## Percentiles

**A percentile is a value below which a certain percentage of observations lie.** The 78th percentile is the value that 78% of the data sits at or below. Two directions to work it:

**Percentile rank of a value** — rank a value among the rest:

$$
\text{percentile rank of } x = \frac{\text{number of values below } x}{n}\times 100
$$

For the 14-value set $\left[2,2,3,4,5,5,6,7,8,8,8,9,9,10\right]$, the value 9 has 11 values below it, so its percentile rank is $\frac{11}{14}\times 100 \approx 78.57\%$ — 9 sits near the top of this data.

**Value at a given percentile** — go the other way, from a percentile to the value. A common position formula gives the *rank* of the value you want:

$$
\text{position} = \frac{p}{100}\,(n+1)
$$

For the 25th percentile of the same set: $\frac{25}{100}\times 15 = 3.75$ — so the value lies between the 3rd and 4th sorted observations, interpolating to about 3.5.

## Quartiles

**Quartiles** are just the three percentiles that cut sorted data into four equal quarters:

- **Q1** = 25th percentile — a quarter of the data is below it
- **Q2** = 50th percentile — the **median**
- **Q3** = 75th percentile — three quarters of the data is below it

```
   |------|------|------|------|
  min    Q1    Q2(med) Q3    max
        25%    50%    75%
```

They're the backbone of the [5-number summary](./five-number-summary) on the next page.

## Why a quant cares: VaR is a percentile

Here's the direct payoff: **Value-at-Risk is literally a percentile of the return distribution.** The **5% VaR** is the 5th percentile of returns — the loss you'd expect to *exceed* only about one day in twenty. No distribution assumption required; you just read it off the data.

```python
import numpy as np
rng = np.random.default_rng(2)

rets = rng.normal(0.05, 1.0, 1000)              # daily returns (%)
q1, med, q3 = np.percentile(rets, [25, 50, 75])
var5 = np.percentile(rets, 5)                   # 5% Value-at-Risk

print(f"Q1={q1:+.2f}%   median={med:+.2f}%   Q3={q3:+.2f}%")
print(f"5th percentile (5% VaR): {var5:+.2f}%  <- ~1 day in 20 is worse than this")
```

Percentiles are how risk gets quantified distribution-free — see [Valuation & Risk Management](/docs/Finance/valuation-and-risk) for where this leads.
