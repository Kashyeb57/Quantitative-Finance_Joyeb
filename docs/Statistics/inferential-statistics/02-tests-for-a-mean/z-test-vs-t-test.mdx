# When to Use a t-test vs a z-test

Both tests answer the same question — *is this mean different?* — so the only thing left to decide is **which one**. Two yes/no questions settle it.

Read it top-down:

1. **Do you know the population standard deviation $\sigma$?**
   - **No** → use the **t-test.** (You'll estimate the spread with the sample $s$.)
   - **Yes** → ask the second question.
2. **Is the sample size above 30?**
   - **Yes** → use the **z-test.**
   - **No** → use the **t-test.**

The z-test wins on **exactly one path** — you know $\sigma$ *and* $n > 30$. In every other case, the [t-test](/docs/Statistics/inferential-statistics/tests-for-a-mean/t-test) is the honest choice.

## Side by side

| | **z-test** | **t-test** |
|---|---|---|
| Population σ | **known** | **unknown** (estimated by sample $s$) |
| Sample size | large, $n \ge 30$ | any, especially small $n < 30$ |
| Reference curve | standard normal | Student-t with $\text{dof} = n-1$ |
| Two-tailed 95% critical value | fixed $\pm 1.96$ | $\pm t_{\text{dof}}$ (wider; e.g. $\pm 2.045$ at dof 29) |
| Tails | thinner | fatter (more room for extremes) |

The two converge: as $n$ grows, the sample $s$ nails down $\sigma$, the t-tails thin, and the t-critical value slides toward $1.96$. That's why "$n \ge 30$" is the rough line where the distinction stops mattering — drag the **df** slider on the [t-distribution lab](/docs/Statistics/inferential-statistics/tests-for-a-mean/student-t-distribution) to watch it happen.

```python
import numpy as np

def choose_test(sigma_known: bool, n: int) -> str:
    if not sigma_known:
        return "t-test  (σ unknown → estimate with sample s)"
    return "z-test" if n > 30 else "t-test  (σ known but small sample)"

for sigma_known, n in [(True, 50), (True, 12), (False, 200), (False, 8)]:
    print(f"σ known={sigma_known!s:5}  n={n:>3}  ->  {choose_test(sigma_known, n)}")
```

## Why a quant cares

In practice the tree almost always dead-ends at the t-test, and knowing *why* keeps you from overstating confidence:

- **You essentially never know σ in markets.** True volatility is unobservable and time-varying; you estimate it from returns. So the correct default for testing a mean return or a Sharpe ratio is the **t-test**, full stop.
- **The z-test is the large-sample convenience limit.** With thousands of daily observations the two agree, so people report "z-stats" — fine when $n$ is huge, misleading on a short or regime-limited history.
- **Small samples are where the choice bites.** Judging a strategy on a year of data ($n \approx 252$ days, but far fewer *independent* observations after autocorrelation) is exactly when the fatter t-tails save you from calling noise an edge.
