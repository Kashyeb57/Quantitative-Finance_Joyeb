### 17.1 Second-Order Linear Equations

**General Form (homogeneous, constant coefficients):**
$$
ay'' + by' + cy = 0
$$

**AUXILIARY EQUATION:** $ar^2 + br + c = 0$

Solve for $r$. There are three cases:

1. **Two real roots** $r_1 \neq r_2$:
   $$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$$
2. **Repeated real root** $r_1 = r_2 = r$:
   $$y = (C_1 + C_2 x)e^{rx}$$
3. **Complex roots** $r = \alpha \pm \beta i$:
   $$y = e^{\alpha x}(C_1 \cos(\beta x) + C_2 \sin(\beta x))$$

Case 3 gives oscillations whose amplitude is shaped by the envelope $e^{\alpha x}$:

- $\alpha < 0$: **decaying** oscillation (amplitude shrinks to $0$)
- $\alpha = 0$: **sustained** oscillation (constant amplitude)
- $\alpha > 0$: **growing** oscillation (amplitude blows up)

### 17.2 Nonhomogeneous Equations

**General Form (non-homogeneous):**
$$
ay'' + by' + cy = G(x)
$$

**GENERAL SOLUTION:**
$$
y = y_p + y_c
$$
- $y_c = \text{complementary solution}$ (solution to the homogeneous part)
- $y_p = \text{particular solution}$ (any one solution to the full equation)

**METHOD OF UNDETERMINED COEFFICIENTS:**

| $G(x)$ | Try $y_p =$ |
| :--- | :--- |
| Polynomial of degree $n$ | $A_n x^n + \dots + A_0$ |
| $C e^{kx}$ | $A e^{kx}$ |
| $C \cos(kx)$ or $C \sin(kx)$ | $A \cos(kx) + B \sin(kx)$ |

### 17.3 Spring-Mass System

$$
m x'' + c x' + k x = F(t)
$$
Where:
- $m = \text{mass}$
- $c = \text{damping constant}$
- $k = \text{spring constant}$
- $F(t) = \text{external force}$

**Undamped free oscillation** ($c=0, F=0$):
$$
x'' + \omega_0^2 x = 0 \quad \text{where } \omega_0 = \sqrt{\frac{k}{m}}
$$
$$
x(t) = A \cos(\omega_0 t) + B \sin(\omega_0 t) \quad \text{(pure oscillation)}
$$

**Undamped free oscillation** ($c = 0$): the mass swings forever with constant amplitude — a pure sinusoid $x(t) = A\cos(\omega_0 t) + B\sin(\omega_0 t)$.

### 17.4 Series Solutions

For variable-coefficient ODEs, try a power series solution:
$$
y = \sum_{n=0}^{\infty} c_n x^n = c_0 + c_1 x + c_2 x^2 + c_3 x^3 + \dots
$$

Substitute into the ODE and match coefficients.

**Example:** $y'' - y = 0$
$$
\implies y = \cosh(x) = 1 + \frac{x^2}{2!} + \frac{x^4}{4!} + \dots
$$
$$
\text{or } y = \sinh(x) = x + \frac{x^3}{3!} + \frac{x^5}{5!} + \dots
$$
