### 13.1–13.2 Vector Functions and Derivatives

```
  r(t) = <f(t), g(t), h(t)>     (space curve)

  Example: Helix
  r(t) = <cos(t), sin(t), t>

       z
       |        ← helix spiraling up
       |      *
       |    *
       |   *
       |  *      *
       | *     *
       |      *
       +──────────> y
      /  *  *
     x

  Derivative (tangent vector):
  r'(t) = <f'(t), g'(t), h'(t)>

  r'(t) is TANGENT to the curve at each point.
```

### 13.3 Arc Length and Curvature

```
  Arc Length: L = ∫_a^b |r'(t)| dt

  Curvature κ measures how sharply a curve bends:
  κ = |r'(t) × r''(t)| / |r'(t)|³

  Low κ:              High κ:
  (gentle curve)      (sharp curve)
        ────           )(
  almost straight    tight spiral

  κ = 0:  straight line
  κ = 1/r: circle of radius r
```

### 13.4 Velocity and Acceleration

$$
\mathbf{r}(t) = \text{position}, \qquad
\mathbf{v}(t) = \mathbf{r}'(t) = \text{velocity}, \qquad
\mathbf{a}(t) = \mathbf{v}'(t) = \mathbf{r}''(t) = \text{acceleration}
$$

$$
\text{Speed} = |\mathbf{v}(t)|
$$

**Projectile motion:**

$$
\mathbf{r}(t) = \left\langle\, v_0\cos(\alpha)\,t,\ \; v_0\sin(\alpha)\,t - \tfrac{1}{2}g t^2 \,\right\rangle
$$

The trajectory is a downward parabola: it rises to a maximum height, then falls symmetrically back to the ground.
