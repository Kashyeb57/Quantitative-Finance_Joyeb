### 11.1 Sequences

A sequence $\{a_n\}$ is a list: $a_1, a_2, a_3, \ldots$

A **convergent** sequence settles toward a limit $L$; a **divergent** sequence has no finite limit (here it grows without bound).

$$
\lim_{n\to\infty} a_n = L \quad\text{(converges)} \qquad\text{OR}\qquad \text{limit DNE (diverges)}
$$

### 11.2 Series

A **series** is the sum of sequence terms:

$$
S = a_1 + a_2 + a_3 + \cdots = \sum a_n
$$

with **partial sums** $S_n = a_1 + a_2 + \cdots + a_n$. The series **converges** if $\displaystyle\lim_{n\to\infty} S_n = S$ (finite).

**Geometric series:**

$$
\sum a r^{\,n} = \frac{a}{1-r} \qquad\text{for } |r| < 1
$$

<HandPlot
  title="|r| < 1: partial sums converge to S"

<HandPlot
  title="|r| ≥ 1: partial sums diverge"

**Test for divergence:** if $\displaystyle\lim_{n\to\infty} a_n \neq 0$, then $\sum a_n$ **diverges** (a necessary condition!).

### 11.3 The Integral Test

```
  If f(n) = aₙ and f is continuous, positive, DECREASING:

  Σaₙ converges  ⟺  ∫_1^∞ f(x)dx converges

  y  a₁            Series sum ≈ integral (area)
  |  ████
  |  ████ a₂        Integral: shaded
  |  ████ ████      Series:   rectangles
  |  ████ ████ ████
  +──1────2────3────> n

  p-SERIES: Σ 1/nᵖ
  converges if p > 1
  diverges  if p ≤ 1
```

### 11.4–11.6 Convergence Tests Summary

```
  ┌─────────────────────────────────────────────────────────────┐
  │ TEST              WHEN TO USE          RESULT               │
  ├─────────────────────────────────────────────────────────────┤
  │ Divergence Test   Always try first     aₙ↛0 → diverges     │
  │ Geometric Series  Σarⁿ form           |r|<1 conv, |r|≥1 div│
  │ p-Series          Σ1/nᵖ form          p>1 conv, p≤1 div    │
  │ Integral Test     f(n)=aₙ, decreasing ∫ converges ↔ Σ conv │
  │ Comparison Test   Compare to known    squeeze argument      │
  │ Limit Comparison  aₙ~bₙ similar form  lim(aₙ/bₙ)=L>0      │
  │ Alternating Series (-1)ⁿaₙ, aₙ↘0     converges!           │
  │ Ratio Test        factorials/powers   L=lim|aₙ₊₁/aₙ|<1→cv │
  │ Root Test         nᵗʰ powers          L=lim|aₙ|^(1/n)<1→cv│
  └─────────────────────────────────────────────────────────────┘
```

**Ratio Test visual:**
```
  L = lim |aₙ₊₁/aₙ|
      n→∞

  L < 1  →  CONVERGES absolutely
  L > 1  →  DIVERGES
  L = 1  →  INCONCLUSIVE (try another test)
```

### 11.8–11.9 Power Series

```
  Σ cₙ(x−a)ⁿ = c₀ + c₁(x−a) + c₂(x−a)² + ...

  RADIUS OF CONVERGENCE R:
  - Series converges for |x−a| < R
  - Series diverges  for |x−a| > R
  - Endpoints: check separately!

  Number line:
  ───────[────────────────────]───────>
         a−R        a       a+R
         ↑                   ↑
     might converge       might converge
         or diverge       or diverge

  Find R using Ratio Test: R = lim |cₙ/cₙ₊₁|

  Key example:
  1/(1−x) = Σ xⁿ = 1 + x + x² + x³ + ...  for |x| < 1
```

### 11.10 Taylor and Maclaurin Series

```
  f(x) = Σ f⁽ⁿ⁾(a)/n! · (x−a)ⁿ    (Taylor series centered at a)

  When a = 0: MACLAURIN SERIES

  ┌──────────────────────────────────────────────────────┐
  │  eˣ   = 1 + x + x²/2! + x³/3! + x⁴/4! + ...        │
  │  sin(x)= x − x³/3! + x⁵/5! − x⁷/7! + ...           │
  │  cos(x)= 1 − x²/2! + x⁴/4! − x⁶/6! + ...           │
  │  ln(1+x)= x − x²/2 + x³/3 − x⁴/4 + ...  (|x|<1)   │
  │  1/(1−x)= 1 + x + x² + x³ + ...          (|x|<1)   │
  └──────────────────────────────────────────────────────┘
```

**Visual: approximating $\sin(x)$ with Taylor polynomials** — each higher-degree polynomial ($T_1 = x$, then $T_3 = x - x^3/6$, then $T_5 = x - x^3/6 + x^5/120$) hugs the true curve over a wider interval:
