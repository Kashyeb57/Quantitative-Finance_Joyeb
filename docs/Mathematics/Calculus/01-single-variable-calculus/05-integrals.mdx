### 5.1 Areas and Distances

**GOAL:** Area under $f(x)$ from $a$ to $b$.

**Step 1 — Divide $[a, b]$ into $n$ rectangles.** We slice the region into strips of equal width and sum their areas. The tops of the rectangles trace out the curve $f$; the partition points are $x_0 = a, x_1, x_2, \dots, x_n = b$.

<HandPlot

  range={[0, 4.5]}
  curves={[
    { f: (x) => 0.5 + 0.9 * x + 0.12 * x * x, color: 'ink', label: 'f(x)' },
  ]}
  marks={[
    { x: 0.5, label: 'x₀=a' },
    { x: 1.5, label: 'x₁' },
    { x: 2.5, label: 'x₂' },
    { x: 3.5, label: 'x₄=b' },
  ]}
  caption="Rᵢ = f(xᵢ)·Δx — the strips fill the region under f"
/>

Width of each strip:

$$
\Delta x = \frac{b - a}{n}, \qquad R_n = f(x_1)\,\Delta x + f(x_2)\,\Delta x + \cdots + f(x_n)\,\Delta x
$$

**Step 2 — Take $n \to \infty$.** As $n$ increases, the staircase of rectangles hugs the curve more tightly and the approximation improves:

- $n = 4$: a coarse staircase, visible gaps and overshoots.
- $n = 8$: gaps roughly halved.
- $n \to \infty$: the error vanishes and $R_n$ converges to the exact area.

### 5.2 The Definite Integral

**Definition:**

$$
\int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*)\,\Delta x
$$

**Geometric interpretation:**

- $f(x) \ge 0$:  $\displaystyle\int_a^b f\,dx$ = area **above** the $x$-axis.
- $f(x) \le 0$:  $\displaystyle\int_a^b f\,dx$ = $-(\text{area below the }x\text{-axis})$.
- Mixed:  $\displaystyle\int_a^b f\,dx$ = **net signed area**.

/>

**Properties:**
```
  ∫_a^a f dx = 0
  ∫_a^b f dx = −∫_b^a f dx
  ∫_a^b [f±g] dx = ∫f dx ± ∫g dx
  ∫_a^b c·f dx = c·∫_a^b f dx
  ∫_a^b f dx = ∫_a^c f dx + ∫_c^b f dx
```

### 5.3 The Fundamental Theorem of Calculus

**THE most important theorem in calculus — links differentiation and integration.**

**FTC Part 1:**

$$
g(x) = \int_a^x f(t)\,dt \quad\Longrightarrow\quad g'(x) = f(x)
$$

Differentiating an integral gives back the integrand. Visualize $g(x)$ as the **accumulated area** from $a$ up to $x$: the shaded region under $f$ grows as the right edge $x$ slides rightward. Its rate of growth, $g'(x)$, equals the current height of the curve, $f(x)$.

**FTC Part 2 (Evaluation Theorem):**

$$
\int_a^b f(x)\,dx = F(b) - F(a) \qquad \text{where } F' = f
$$

This lets us compute areas exactly!

**Example:**

$$
\int_0^1 x^2\,dx, \quad F(x) = \frac{x^3}{3}, \quad = F(1) - F(0) = \frac{1}{3} - 0 = \frac{1}{3}
$$

### 5.4 Indefinite Integrals and Net Change

```
  ∫ f(x) dx = F(x) + C     (general antiderivative)

  Net Change Theorem:
  ∫_a^b F'(x) dx = F(b) − F(a)

  If v(t) = velocity:
  ∫_a^b v(t) dt = displacement (net change in position)
  ∫_a^b |v(t)| dt = total distance traveled
```

### 5.5 The Substitution Rule

**Reverse chain rule for integration:**

```
  ∫ f(g(x))·g'(x) dx  =  ∫ f(u) du     where u = g(x)

  STEPS:
  1. Choose u = g(x)  (the "inside" function)
  2. Compute du = g'(x)dx
  3. Rewrite integral entirely in u
  4. Integrate
  5. Substitute back

  Example: ∫ 2x·cos(x²) dx
    u = x²
    du = 2x dx
    = ∫ cos(u) du
    = sin(u) + C
    = sin(x²) + C
```
