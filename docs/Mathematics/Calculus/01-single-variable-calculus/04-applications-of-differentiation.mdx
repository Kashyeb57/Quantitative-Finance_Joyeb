**Finding extrema:**
1. **Extreme Value Theorem**: If $f$ is continuous on $[a,b]$, then $f$ attains both an absolute maximum and absolute minimum.
2. **Critical numbers**: $f'(c) = 0$ OR $f'(c)$ is undefined.
3. **Check**: Evaluate $f$ at critical points + endpoints to find the absolute extrema.

### 4.2 The Mean Value Theorem

**Rolle's Theorem:** If $f(a) = f(b)$ and $f$ is continuous on $[a,b]$ and differentiable on $(a,b)$, then $\exists\, c \in (a,b)$ where $f'(c) = 0$.

<HandPlot
  title="Rolle's Theorem"
  xLabel="x" yLabel="y"
  domain={[1, 5]}
  range={[-1.6, 1]}
  curves={[
    { f: (x) => 0.3 * (x - 3) * (x - 3) - 1.2, color: 'ink', label: 'f(x)' },
  ]}
  points={[
    { x: 1, y: 0, label: 'f(a)', color: 'blue' },
    { x: 5, y: 0, label: 'f(b)', color: 'blue' },
    { x: 3, y: -1.2, label: "f'(c)=0", color: 'red' },
  ]}
  marks={[{ x: 3, label: 'c' }]}
/>

**Mean Value Theorem (MVT):** $\exists\, c \in (a,b)$ where

$$
f'(c) = \frac{f(b) - f(a)}{b - a}
$$

The tangent at $c$ is **parallel** to the secant line joining $\bigl(a, f(a)\bigr)$ and $\bigl(b, f(b)\bigr)$ — its slope equals the average rate of change.

### 4.3 How Derivatives Affect Graph Shape

- $f'(x) > 0 \implies f$ is **INCREASING** ↗
- $f'(x) < 0 \implies f$ is **DECREASING** ↘
- $f'(x) = 0 \implies f$ has a horizontal tangent (potential extremum)

- $f''(x) > 0 \implies f$ is **CONCAVE UP** ∪
- $f''(x) < 0 \implies f$ is **CONCAVE DOWN** ∩
- $f''(x) = 0 \implies$ possible **INFLECTION POINT**

**Full picture** — a curve carrying a local max, a local min, and an inflection point where concavity flips:

**Second Derivative Test:**
**At critical point $c$ where $f'(c) = 0$:**
- $f''(c) > 0 \implies$ local **MINIMUM** (concave up = bowl) ∪
- $f''(c) < 0 \implies$ local **MAXIMUM** (concave down = hill) ∩
- $f''(c) = 0 \implies$ test inconclusive (need more analysis)

### 4.4 L'Hôpital's Rule

For **0/0** or **∞/∞** indeterminate forms:

$$
\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}
$$
*(Provided the right-hand limit exists)*

**Examples:**
$$
\lim_{x \to 0} \frac{\sin(x)}{x} \quad \left[ \frac{0}{0} \text{ form} \right] \implies \lim_{x \to 0} \frac{\cos(x)}{1} = 1
$$
$$
\lim_{x \to \infty} \frac{x}{e^x} \quad \left[ \frac{\infty}{\infty} \text{ form} \right] \implies \lim_{x \to \infty} \frac{1}{e^x} = 0
$$

**Other indeterminate forms — convert first:**
- $0 \cdot \infty \implies$ rewrite as $\frac{0}{1/\infty}$ or $\frac{\infty}{1/0}$
- $\infty - \infty \implies$ find common denominator
- $0^0, 1^\infty, \infty^0 \implies$ take logarithm first

### 4.5 Curve Sketching Checklist

**STEP-BY-STEP:**
1. **Domain**: Where is $f$ defined?
2. **Intercepts**: Set $f=0$ (x-int), $x=0$ (y-int)
3. **Symmetry**: Even? $f(-x)=f(x)$ Odd? $f(-x)=-f(x)$
4. **Asymptotes**: Vertical (where $f \to \infty$), Horizontal (limits at $\pm \infty$)
5. **Increase/Dec**: Sign of $f'$
6. **Local Extrema**: $f'=0$ and sign change
7. **Concavity**: Sign of $f''$
8. **Inflection pts**: $f''$ changes sign
9. **Sketch!**

### 4.7 Optimization Problems

**STRATEGY:**
1. **Read carefully** — what to maximize/minimize?
2. **Draw a diagram**
3. **Label variables**, write constraint equation
4. **Write objective function** in ONE variable
5. **Find critical points** (set derivative = $0$)
6. **Verify** it's max/min (2nd derivative test or interval check)

**CLASSIC EXAMPLE:** Maximize area of rectangle with perimeter = 40.
$$
\begin{aligned}
P &= 2x + 2y = 40 \implies y = 20 - x \\
A &= xy = x(20 - x) = 20x - x^2 \\
A' &= 20 - 2x = 0 \implies x = 10, y = 10
\end{aligned}
$$
> A square maximizes the area!

### 4.8 Newton's Method

Iterative root-finding using tangent lines. From a guess $x_1$, follow the tangent down to the $x$-axis to get a better guess $x_2$:

$$
x_2 = x_1 - \frac{f(x_1)}{f'(x_1)}, \qquad x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}
$$

### 4.9 Antiderivatives

F is an antiderivative of f if F'(x) = f(x).

$$
\int f(x) dx = F(x) + C \quad (C = \text{constant of integration})
$$

**Example:**
$\frac{d}{dx}[x^3] = 3x^2 \implies$ antiderivative of $3x^2$ is $x^3 + C$

**Key antiderivatives:**

| $f(x)$ | $F(x) = \int f dx$ |
|---|---|
| $x^n \ (n \neq -1)$ | $\frac{x^{n+1}}{n+1} + C$ |
| $1/x$ | $\ln\|x\| + C$ |
| $e^x$ | $e^x + C$ |
| $\sin(x)$ | $-\cos(x) + C$ |
| $\cos(x)$ | $\sin(x) + C$ |
