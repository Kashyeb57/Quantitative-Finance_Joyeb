### 2.1 The Tangent and Velocity Problems

The **tangent** line at a point P is the limit of **secant** lines through P and a nearby point Q as Q slides toward P. Drag Q toward P:

<SecantTangent />

The secant through $P(a, f(a))$ and $Q(x, f(x))$ has slope

$$
m_{PQ} = \frac{f(x) - f(a)}{x - a}.
$$

As $x \to a$ the secant becomes the tangent, whose slope is the **derivative**:

$$
m_{\tan} = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}.
$$

### 2.2 The Limit of a Function

$$
\lim_{x \to a} f(x) = L
$$

**Meaning:** $f(x)$ gets arbitrarily close to $L$ as $x$ approaches $a$ (from either side). The value $f(a)$ might not exist — the limit can still equal $L$.

  marks={[{ y: 2, label: 'L' }, { x: 0, label: 'x = a' }]}

Left side $\to L$ **and** right side $\to L$, so the limit exists and equals $L$.

**When limits do NOT exist:**

**Case 1 — Jump:** the left and right limits disagree, so no single limit exists.

### 2.3 Limit Laws

If lim f(x) = L and lim g(x) = M (as x→a), then:

| Law | Formula |
|-----|---------|
| **Sum** | $\lim_{x \to a} [f(x) + g(x)] = L + M$ |
| **Difference** | $\lim_{x \to a} [f(x) - g(x)] = L - M$ |
| **Constant** | $\lim_{x \to a} [c \cdot f(x)] = c \cdot L$ |
| **Product** | $\lim_{x \to a} [f(x) \cdot g(x)] = L \cdot M$ |
| **Quotient** | $\lim_{x \to a} \left[\frac{f(x)}{g(x)}\right] = \frac{L}{M}$ (if $M \neq 0$) |
| **Power** | $\lim_{x \to a} [f(x)]^n = L^n$ |
| **Root** | $\lim_{x \to a} \sqrt[n]{f(x)} = \sqrt[n]{L}$ |

**The Squeeze Theorem:**

$$
\text{If } f(x) \le g(x) \le h(x) \text{ near } x = a \quad\text{and}\quad \lim_{x \to a} f(x) = \lim_{x \to a} h(x) = L, \quad\text{then } \lim_{x \to a} g(x) = L.
$$

<HandPlot
  title="Squeeze Theorem — f ≤ g ≤ h all → L"
  xLabel="x" yLabel="y"
  domain={[-2, 2]}
  range={[-0.5, 2]}
  curves={[
    { f: (x) => 1 + 0.5 * x * x, color: 'blue', label: 'h(x)' },
    { f: (x) => 1 + 0.3 * x * x * Math.cos(4 * x), color: 'ink', label: 'g(x)' },
    { f: (x) => 1 - 0.5 * x * x, color: 'green', label: 'f(x)' },
  ]}
  marks={[{ y: 1, label: 'L' }, { x: 0, label: 'x = a' }]}
/>

$$
\textbf{Key result:}\quad \lim_{x \to 0} \frac{\sin x}{x} = 1.
$$

### 2.4 The Precise Definition (ε-δ)

$$
\lim_{x \to a} f(x) = L \quad\text{means:}\quad \text{for every } \varepsilon > 0 \text{ there is a } \delta > 0 \text{ with } 0 < |x - a| < \delta \;\implies\; |f(x) - L| < \varepsilon.
$$

### 2.5 Continuity

A function f is **continuous at a** if all three hold:

1. $f(a)$ is defined
2. $\lim_{x \to a} f(x)$ exists
3. $\lim_{x \to a} f(x) = f(a)$

**Continuous:** a smooth, unbroken curve — you can draw it without lifting your pen.

<HandPlot
  title="Continuous function"
  xLabel="x" yLabel="y"
  domain={[-3, 3]}
  range={[-1, 3]}
  curves={[
    { f: (x) => 2 - 0.25 * x * x, color: 'ink', label: 'f(x)' },
  ]}
/>

**Discontinuities** come in three flavours — *removable* (a single hole), *jump* (a step gap where left ≠ right), and *infinite* (the curve blows up at a vertical asymptote):

<HandPlot
  title="Infinite discontinuity — blows up at x = 0"
  xLabel="x" yLabel="y"
  domain={[-3, 3]}
  range={[-6, 6]}
  curves={[
    { f: (x) => 1 / x, color: 'red', label: 'f(x) = 1/x' },
  ]}
  marks={[{ x: 0, label: 'x = 0' }]}
/>

**Intermediate Value Theorem:**

$$
\text{If } f \text{ is continuous on } [a,b] \text{ and } N \text{ lies between } f(a) \text{ and } f(b), \text{ then } \exists\, c \in (a,b) \text{ with } f(c) = N.
$$

<HandPlot
  title="Intermediate Value Theorem"
  xLabel="x" yLabel="y"
  domain={[0, 4]}
  range={[0, 4]}
  curves={[
    { f: (x) => 0.6 + 0.7 * x + 0.15 * x * x, color: 'ink', label: 'f(x)' },
  ]}
  points={[{ x: 2, y: 0.6 + 1.4 + 0.6, label: 'c: f(c) = N', color: 'red' }]}
  marks={[{ y: 2.6, label: 'N' }, { x: 0, label: 'a' }, { x: 4, label: 'b' }]}
/>

The continuous curve cannot skip level $N$ — it is guaranteed to cross it at some $c$ in $(a,b)$.

> **Quant Finance:** Guarantees a yield exists for bond pricing; root-finding for implied volatility.

$$
\begin{aligned}
\lim_{x \to \infty} x^n &= \infty \quad (n>0) & \lim_{x \to \infty} \frac{1}{x^n} &= 0 \\
\lim_{x \to \infty} e^x &= \infty & \lim_{x \to -\infty} e^x &= 0 \\
\lim_{x \to \infty} \ln(x) &= \infty & & 
\end{aligned}
$$

### 2.7 Derivatives and Rates of Change

The **derivative** is the slope of the tangent line = instantaneous rate of change.

$$
f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}.
$$

Visually, the secant through $P\big(a, f(a)\big)$ and $Q\big(a+h, f(a+h)\big)$ has slope $\Delta f / h$; as $h \to 0$, $Q$ slides into $P$ and the secant becomes the tangent.

<HandPlot
  title="Derivative — secant → tangent as h → 0"
  xLabel="x" yLabel="y"
  domain={[0, 4]}
  range={[0, 5]}
  curves={[
    { f: (x) => 0.35 * x * x, color: 'ink', label: 'y = f(x)' },
    { f: (x) => 0.35 * 1 + 0.7 * (x - 1), color: 'blue', dash: true, label: "tangent at P" },
  ]}
  points={[
    { x: 1, y: 0.35, label: 'P', color: 'red' },
    { x: 3, y: 0.35 * 9, label: 'Q', color: 'green' },
  ]}
/>

**Three interpretations:**
1. **Geometric:** slope of tangent line to $y=f(x)$ at $x=a$
2. **Physical:** instantaneous rate of change
3. **Kinematic:** velocity if $f$ is a position function

> **Quant Finance:** Delta = ∂V/∂S (option price sensitivity to underlying); DV01 = ∂P/∂y (bond price sensitivity to yield)

### 2.8 The Derivative as a Function

$$
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}.
$$

From the original function we derive a **new** function $f'(x)$. For $f(x) = x^2$ (a parabola), the derivative $f'(x) = 2x$ is a straight line:

<HandPlot
  title="f(x) = x²  and its derivative  f'(x) = 2x"
  xLabel="x" yLabel="y"
  domain={[-3, 3]}
  range={[-6, 9]}
  curves={[
    { f: (x) => x * x, color: 'ink', label: 'f(x) = x²' },
    { f: (x) => 2 * x, color: 'blue', dash: true, label: "f'(x) = 2x" },
  ]}
/>

**Notations for derivative:**
| Notation | Name | Usage |
|----------|------|-------|
| $f'(x)$ | Lagrange | Most common in calculus |
| $\frac{df}{dx}$ | Leibniz | Highlights the ratio of differentials |
| $Df(x)$ | Euler | Operator notation |
| $\dot{x}$ | Newton | Time derivative, common in physics |

**Higher Derivatives:**
| Order | Function | Interpretation |
|---|---|---|
| $0$ | $f(x)$ | Position |
| $1$ | $f'(x)$ | Velocity (1st derivative) |
| $2$ | $f''(x)$ | Acceleration (2nd derivative) |
| $3$ | $f'''(x)$ | Jerk (3rd derivative) |

$$
f''(x) = [f'(x)]' = \frac{d^2f}{dx^2}
$$

> **Quant Finance:** Gamma = ∂²V/∂S² (rate of change of Delta); Convexity = ∂²P/∂y² for bonds.
