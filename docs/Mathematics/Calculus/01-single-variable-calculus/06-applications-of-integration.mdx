### 6.2 Volumes (Disk Method)

Rotate $f(x)$ around x-axis $\implies$ solid of revolution.
$$
V = \pi \int_a^b [f(x)]^2 \, dx
$$

<HandPlot
  title="Solid of Revolution (Disk Method)"
  xLabel="x" yLabel="y"
  domain={[0, 4]} range={[-3, 3]}
  curves={[
    { f: (x) => Math.sqrt(x), color: 'blue', label: 'y = √x' },
    { f: (x) => -Math.sqrt(x), color: 'gray' }
  ]}
  polygons={[
    { points: [[2, -Math.sqrt(2)], [2, Math.sqrt(2)], [2.2, Math.sqrt(2)], [2.2, -Math.sqrt(2)]], color: 'red' }
  ]}
  marks={[
    { x: 2, y: Math.sqrt(2)/2, color: 'pencil', label: 'radius r = f(x)' },
    { x: 2.1, y: -0.5, color: 'pencil', label: 'dx' }
  ]}
  caption="Cross-section is a DISK with radius f(x) and thickness dx. Volume = sum of infinitely thin disk areas."
  height={300}
/>

**Washer Method** (hole in the middle):
$$
V = \pi \int_a^b \left( [f(x)]^2 - [g(x)]^2 \right) \, dx
$$
*(Outer radius squared minus Inner radius squared)*

### 6.3 Shell Method

$$
V = \int 2\pi \cdot (\text{radius}) \cdot (\text{height}) \cdot (\text{thickness})
$$

### 6.4–6.5 Work and Average Value

**Work:**

$$
W = \int_a^b F(x)\, dx \qquad \text{(when force } F \text{ varies with position } x\text{)}
$$

<HandPlot
  title="Work = area under the force curve"

**Average Value:**

$$
f_{\text{avg}} = \frac{1}{b - a} \int_a^b f(x)\, dx
$$
