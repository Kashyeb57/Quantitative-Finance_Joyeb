### 0.1 The Two Central Problems of Calculus

Calculus is built on two problems: **finding areas** and **finding slopes of curves**.

---

#### The Area Problem (Integral Calculus)

We want the exact area under a curve. Since we can't compute curved areas directly, we approximate with rectangles and take a limit.

<HandPlot
  title="Area under a curve"
  xLabel="x" yLabel="y"
  domain={[-3, 3]}
  range={[0, 7]}
  curves={[
    { f: (x) => 6 * Math.exp(-x * x / 2.2), color: 'ink', label: 'f(x)' },
  ]}
  marks={[{ x: -1.6, label: 'a' }, { x: 1.6, label: 'b' }]}
/>

The shaded region between $a$ and $b$ is the area we want to compute under the curve $f(x)$.

**Riemann Sum approach** — divide [a,b] into n rectangles:

<HandPlot
  title="Area Approximation using Rectangles"
  xLabel="x" yLabel="y"
  domain={[0, 4]} range={[0, 5]}
  curves={[{ f: (x) => -0.2 * Math.pow(x - 2, 2) + 4, color: 'blue' }]}
  polygons={[
    { points: [[0.5,0], [0.5,3.55], [1.5,3.55], [1.5,0]], color: 'green' },
    { points: [[1.5,0], [1.5,3.95], [2.5,3.95], [2.5,0]], color: 'green' },
    { points: [[2.5,0], [2.5,3.55], [3.5,3.55], [3.5,0]], color: 'green' }
  ]}
  marks={[
    { x: 0.5, y: -0.2, color: 'pencil', label: 'a' },
    { x: 3.5, y: -0.2, color: 'pencil', label: 'b' }
  ]}
  caption="Each rectangle has width Δx = (b-a)/n and height f(xᵢ*). As n → ∞, approximation becomes exact."
  height={300}
/>


**Formula:**
$$
A = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*) \Delta x \quad \text{where} \quad \Delta x = \frac{b-a}{n}
$$

> **Quant Finance:** Area under a probability density function = probability of an event. Used in option pricing (risk-neutral valuation) and expected value of payoffs.

#### The Tangent Problem (Differential Calculus)

Given a curve, find the slope of the line that just "touches" it at one point.

<HandPlot
  title="The tangent line at a point"
  xLabel="x" yLabel="y"
  domain={[0, 4]}
  range={[0, 9]}
  curves={[
    { f: (x) => x * x * 0.5, color: 'ink', label: 'y = f(x)' },
    { f: (x) => 2 * x - 2, color: 'blue', label: 'tangent at P' },
  ]}
  points={[{ x: 2, y: 2, label: 'P(a, f(a))', color: 'red' }]}
/>

The tangent line is the line that just "touches" the curve $y = f(x)$ at the point $P(a, f(a))$ — its slope is what we want.

**Secant line approach** — take two points and slide Q → P:

<HandPlot
  title="Secant line through P and Q"
  xLabel="x" yLabel="y"
  domain={[0, 4]}
  range={[0, 9]}
  curves={[
    { f: (x) => x * x * 0.5, color: 'ink', label: 'y = f(x)' },
    { f: (x) => 2.5 * x - 3, color: 'blue', label: 'secant PQ' },
  ]}
  points={[
    { x: 2, y: 2, label: 'P(a, f(a))', color: 'red' },
    { x: 3.2, y: 5.12, label: 'Q(x, f(x))', color: 'red' },
  ]}
/>

$$\text{slope of } PQ = \frac{f(x) - f(a)}{x - a}$$

As $x \to a$, the secant line approaches the tangent line:

$$m = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

> **Quant Finance:** Delta (Δ) is the tangent slope of an option price curve vs. underlying price — the hedge ratio.

#### The Velocity Problem

<HandPlot
  title="Position vs. time"
  xLabel="t" yLabel="s(t)"
  domain={[0, 4]}
  range={[0, 9]}
  curves={[
    { f: (x) => x * x * 0.5, color: 'ink', label: 's(t)' },
  ]}
  marks={[{ x: 1, label: 'a' }, { x: 3, label: 'b' }]}
/>

$$\text{Average velocity} = \frac{\Delta s}{\Delta t} = \frac{s(b) - s(a)}{b - a}$$

$$\text{Instantaneous velocity} = \lim_{t \to a} \frac{s(t) - s(a)}{t - a}$$
